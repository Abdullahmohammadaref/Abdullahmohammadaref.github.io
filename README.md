# Portfolio website

**Live website:** https://abdullahmohammadaref.github.io/
## Overview
An interactive website showcasing my projects, skills, and career in 
data science and software engineering.

## Tech stack
- React + Vite
- TypeScript
- HTML5 & Vanilla Extract CSS

## Features
- Detailed overview of machine learning, backend, and full-stack projects.
- My CV is available and ready to download in PDF format.
- Responsive design
- Deployed with GitHub actions and pages

## Prerequisites
- Node.js v22.12.0

## How to run
1. Open terminal in directory of choice and run `git clone https://github.com/Abdullahmohammadaref/Abdullahmohammadaref.github.io`
2. Run `cd Abdullahmohammadaref.github.io`
3. Run `npm install`
4. Run `npm run dev` to run server In development environment or `npm run build` to build the website into static files.
